# Responsive Rules

Regras de adaptação responsiva para web e mobile.

## Mobile-first

- Layout em coluna única.
- Menus tipo hambúrguer quando necessário.
- CTAs principais visíveis e acessíveis.
- Padding ajustado para leitura confortável.

## Desktop

- Grids de 12 colunas.
- Sidebar fixa em áreas administrativas.
- Leitura em largura controlada, idealmente até 800px para texto longo.

## Princípios

- O conteúdo deve reorganizar-se sem perder hierarquia.
- Não depender de componentes demasiado largos em telas pequenas.
- Preservar legibilidade em todas as resoluções comuns.
