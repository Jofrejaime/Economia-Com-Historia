# Accessibility

Regras mínimas para acessibilidade e usabilidade consistentes.

## Requisitos obrigatórios

- Contraste mínimo de 4.5:1 para texto de corpo.
- Botões com altura mínima de 44px.
- Alt text obrigatório para imagens históricas e informativas.
- Uso rigoroso de HTML semântico, incluindo `article`, `section` e headings estruturados.
- Navegação por teclado deve funcionar em todos os fluxos essenciais.

## Direção prática

- Não depender apenas de cor para comunicar estado.
- Garantir foco visível em todos os elementos interativos.
- Evitar blocos densos de informação sem respiro visual.
